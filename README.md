## 技术路线

选题对应课程要求「人脸美颜相机——肤色保护与细节增强」，处理流程划分为七个模块（详见 `设计方案-人脸美颜.md`）：

1. 色彩空间转换与肤色检测
2. 曝光改善（CLAHE + 自适应伽马校正）
3. 空间域皮肤平滑与边缘保护
4. 频率域磨皮与细节增强
5. 轻微运动模糊复原
6. 彩色增强与白平衡
7. 评价与输出

## 数据集

主数据集为 CelebAMask-HQ，获取方式与标签说明见 `data/input/README.md`。数据仅限非商业研究/教学用途，不纳入版本管理，使用 `src/prepare_data.py` 抽取子集并合并掩码。
