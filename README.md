## 实验清单

| 编号 | 实验名称 | 核心内容 |
| --- | --- | --- |
| 实验一 | 数字图像读取及色彩、亮度、对比度变化 | 直方图均衡化与规定化 |
| 实验二 | 数字图像变换与伽马校正 | 不同参数下的伽马校正 |
| 实验三 | 数字图像的噪声去除 | 高斯/椒盐加噪；中值滤波、统计排序滤波 |
| 实验四 | 图像的空间域锐化 | 拉普拉斯锐化；Canny 边缘检测 |
| 实验五 | 频率域低通和高通滤波 | FFT；低通滤波；高通滤波 |
| 实验六 | 数字图像复原 | 高斯模糊/运动模糊；维纳滤波复原 |
| 实验七 | 人脸皮肤颜色分层 | 彩色图像分层提取人脸 |
