# 课程实验

七次课程实验，每次实验一个子目录，建议每个目录内包含：

- `main.m` 或 `main.py`：实验主程序
- `report/`：该次实验报告（按《图像处理课程实验报告-2026》格式）
- 结果图可直接输出到本目录或 `results/`

公共测试图集见 `../assets/实验图集/`。

| 目录 | 实验 |
| --- | --- |
| `exp01_直方图均衡与规定化` | 实验一 直方图均衡化与规定化 |
| `exp02_伽马校正` | 实验二 伽马校正 |
| `exp03_噪声去除` | 实验三 噪声添加与中值/统计排序滤波 |
| `exp04_空间域锐化` | 实验四 拉普拉斯锐化与 Canny 边缘检测 |
| `exp05_频率域滤波` | 实验五 FFT 与低通/高通滤波 |
| `exp06_图像复原` | 实验六 模糊退化与维纳滤波复原 |
| `exp07_人脸肤色分层` | 实验七 彩色图像分层提取人脸 |
