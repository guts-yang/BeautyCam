## 实现方法

1. 在 YCrCb 的 Y 亮度上使用 NumPy rfft2 / irfft2，保留原始色度。lowpass_sigma 表示空间等效高斯标准差，单位为像素，频率网格单位为 cycles/pixel。
2. 输入做完整偶反射延拓，等效 REFLECT_101；处理完裁回原尺寸，避免 FFT 周期连接图像相反边界。
3. 低通传递函数为 H(fx,fy) = exp(-2π²σ²(fx²+fy²))，有符号高频 = 原亮度 − 低频。中间过程不把高频裁成非负数。
4. 用 lowpass_gain × 低频 + highpass_gain × 高频合成，并按掩码内到边界的距离渐变融合。当前 YAML：sigma=3.0、lowpass_gain=1.0、highpass_gain=0.8。
5. 掩码外像素严格不变。空掩码返回副本；两个增益均为 1 时精确返回副本；未改亮度像素不经过色彩转换回写，避免不必要的取整漂移。
6. 处理函数与诊断函数均不修改输入图、掩码或配置，不读写文件，不依赖其他算法模块。

配置优先从传入 cfg 读取；省略 highpass_gain 时仍采用原接口的 0.5 回退值。正式运行与验收应加载仓库 YAML，不能用空配置代替最终参数。

NumPy 的实数 FFT 与频率网格定义参考：[rfft2（1.26）](https://numpy.org/doc/1.26/reference/generated/numpy.fft.rfft2.html)、[rfftfreq（1.26）](https://numpy.org/doc/1.26/reference/generated/numpy.fft.rfftfreq.html)。

## 诊断图契约

显式调用 get_frequency_diagnostics 时始终返回同尺寸 BGR uint8 的 low_frequency 与 high_frequency 两个冻结键：

- 低频图：低频亮度取整后复制到三个通道。
- 高频图：有符号高频加 128 后显示；128 表示零残差，亮于/暗于 128 分别表示正/负残差。显示时的裁剪不参与主处理。
- diagnostics 中的两项布尔值保留为调用方显示偏好，不改变返回键，也不影响主输出；是否调用和保存由公共流水线控制。

评测对全部 40 张执行“主处理 → 诊断 → 再次主处理”，两次主输出逐字节一致，并验证输入未被修改。诊断使用模块处理前输入。额外保存的 log 频谱是输入亮度 FFT 幅度的每图归一化显示，不用于能量计分。

## 隔离评测协议

- 使用 assets/evaluation_manifest.csv 的固定 40 张，不剔除困难样本；清单 SHA-256 为 d9df0cff2d661b0e7f94a763aa932fe6779068a461f904c634d4c79f326cf5a9。
- M4 直接接收 skin GT，避免将 M1 误差混入 M4 定量评价。标签与皮肤 GT 从 512×512 最近邻对齐至 1024×1024 原图。
- 高频残差按项目基线定义：Y − GaussianBlur(Y, sigma=3, REFLECT_101)。在以 11×11 椭圆结构元素腐蚀后的皮肤 GT 内，计算处理后 RMS / 处理前 RMS。
- 高频分母小于 1e-6 或腐蚀区域为空时记录空分数和原因，不把无效样本记为满分。
- 五官标签为 {3,4,5,6,7,10,11,12}。用 CV_32F、3×3 Sobel 求梯度模长 G；EPI = sum(min(G前,G后)) / (sum(max(G前,G后)) + 1e-8)。空区域和零梯度记录无效原因。
- 每张有效图等权宏平均，同时保留中位数、有效数、无效数与逐图分数。
- 五官标签只用于离线评分，没有传给 M4 处理函数。
- scene 列仍是未经人工确认的占位标签，本轮不宣称真实场景分层。

## 本地复现与材料

在 BeautyCam 仓库根目录执行：

```powershell
.\.venv\Scripts\pytest.exe -m "not integration" -q
.\.venv\Scripts\python.exe tools/evaluate_m4.py --data-root data/input/subset
# 复现原始 0.5 增益基线；只覆盖本次运行，不写回配置
.\.venv\Scripts\python.exe tools/evaluate_m4.py --highpass-gain 0.5
```

默认每次创建新的 results/m4_<run>/ 目录；已有输出目录禁止覆盖。定量未达标返回退出码 1，人工审核状态独立记录为 pending。

- results/m4_baseline_20261022/：0.5 增益失败基线。
- results/m4_candidate_20261022/：命令行覆盖为 0.8 的候选试跑。
- results/m4_validation_20261022/：读取最终 YAML 的复跑，作为本轮最终材料。

最终目录内包括：

- summary.json：有效参数、运行环境、清单/算法哈希、有效样本数和验收结果。
- samples.csv：40 张逐图高频 RMS 比率与 EPI。
- outputs/：40 张原尺寸结果。
- diagnostics/：80 张原尺寸低频/有符号高频图。
- spectra/：40 张输入亮度 log 频谱。
