# 课程设计（大作业）

## 目录说明

- `src/`：源码（MATLAB / Python / C++）
- `data/input/`：输入素材（可将需要的图集图片拷入）
- `data/output/`：程序输出结果
- `results/`：评测数据（PSNR/SSIM/OCR 识别率等）与结论
- `report/`：课程设计报告（按《课程设计报告-图像处理-2026》格式）
- `slides/`：答辩 PPT

## 选题

请在以下题目中确定一题（详见 `../docs/任务书及评分标准-数字图像处理2026.docx`）：

1. 手机文档扫描与可读性增强系统
2. 老照片数字修复与彩色增强系统
3. 低照度彩色监控图像增强与复原系统
4. 人脸美颜相机——肤色保护与细节增强
5. 医学影像综合增强与伪彩色显示系统
6. 工业产品表面缺陷检测预处理系统
7. 自选题目（仅限传统方法，不使用深度学习）

## 提交要求

- 每人一份课程设计报告，命名 `学号+姓名+大作业报告书`
- 答辩材料：报告（打印版）、PPT（约 3 分钟）、程序源码、笔记本电脑
- 组内材料合并为一个压缩包，命名 `组别号+全部组员姓名`
